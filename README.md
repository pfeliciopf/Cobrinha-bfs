# Cobrinha-bfs
Jogo da cobrinha em Python controlado automaticamente pelo algoritmo de busca BFS, desenvolvido com Tkinter.

## Funcionalidades

- Interface gráfica com Tkinter.
- Geração aleatória de comida.
- Pontuação automática.
- Busca de caminhos usando BFS.
- Movimentação automática da cobra.

## Tecnologias

- Python
- Tkinter
- Collections (`deque`)
- Random

## Como executar

1. Instale o Python 3.
2. Certifique-se de que o Tkinter está instalado.
3. Execute:

```bash
python3 main.py
```
